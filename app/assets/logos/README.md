# 로그인 버튼 로고 (디자인 리뷰 11/03 #4)

각 회사 공식 자료에서 받은 파일. 모양·색을 바꾸지 않는다.

- `kakao.png`: 카카오디벨로퍼스 카카오 로그인 디자인 리소스(https://developers.kakao.com/tool/resource/login)의 말풍선 심볼을 80×80 PNG로 변환. 디자인 가이드: https://developers.kakao.com/docs/latest/ko/kakaologin/design-guide
- `google.png`: Google 로그인 브랜드 가이드라인의 공식 자료(signin-assets.zip, Android + Web / PNG @4x / Light / 글자 없는 사각 버튼)에서 G 로고 부분(가운데 80×80)만 자름. 가이드: https://developers.google.com/identity/branding-guidelines
- Apple 로고: 아직 없음. 공식 자료(https://developer.apple.com/design/resources/ 의 Sign in with Apple)는 받을 때 Apple 라이선스 동의가 필요하다.
